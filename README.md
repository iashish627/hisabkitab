# HisabKitab

A lightweight inventory, order and business-expense dashboard for small sellers.

## Development

```bash
npm install
npm run dev
```

## Stack

- React + Vite
- React Router
- Lucide icons
- Browser barcode scanning with `@zxing/browser`

The first milestone uses local demo data. Supabase persistence and marketplace integrations will be added in later milestones.
